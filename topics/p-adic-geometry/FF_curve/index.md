There is are three classical cohomology theory (all integral)
1. p-adic etale cohomology of generic fiber (finite Z_p module, + Galois action if X was defined over finite extension of Qp )
2. crystalline cohomology of special fiber (finite W module with phi-semilinear action iso when p inverted)
3. derham cohomology X/O_C (finite O_C module + Hodge filtration)
