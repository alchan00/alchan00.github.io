A= complete DVR uniformizer pi, residue field F_q

Commutative Formal group : F in A[[X,Y]] s.t. for A-> R Huber ring (R^00, +F) a+Fb=F(a,b) becomes an abelian group. 
i.e. F is an abelian group object represented by spfA[[T]].

endomorphism is described by an element f in TA[[T]] s.t. f(F)=F(f,f) f is invertible iff f'(0) is a unit.

f in TA[[T]] s.t. f = pi*T modT^2, f = T^q mod pi.

Main result

1.for each f there exist F_f s.t. f is in End(F_f).

2. different choice of f induces isomorphic group laws. (exist canonical iso)

3. exist map A->End(F_f) sending pi to f.

This unique formal group law given A is called Lubin tate formal group. It has dim 1 ( spfA[[T]] ) and height 1 ( f = T^q mod pi)

ex)

A=Z_p formal mult group G_m is Lubin tate. f = (1+T)^p-1


Lubin tate formal group serve as a moduli space of H^0(X_FF,O(1))
