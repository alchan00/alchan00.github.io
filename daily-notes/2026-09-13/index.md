Class field theory.
Artin reciprocity law, together Kronecker-Weber thm generalize quadratic reciprocity for abelian extensions.
i.e. if K/Q is a splitting field of P(X), and K/Q is abelian, one can find Q(mu_N)>K>Q.
p mod N determines an element of G(K/Q), and its order governs the behavior of how P(X) splits mod p. (ex P splits completely mod p iff Frob_p has order 1)

Extending to non abelian case.
There has to be some shift to representation theory since Frob_p is only a conjugacy class not an element.
Now the key variable for reciprocity is trace(Frob_p). *Brauer–Nesbitt theorem states that these numbers determine a representation.
