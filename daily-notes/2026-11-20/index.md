All are infinity categories.

Let C be a presentable cat then there is a bijection between the following data :

1. Accessible localisation of C (Automatically a presentable category)

2. full sub cat of C, stable under limits and k-filtered colimits for some regular cardinal k

3. stronly saturated class of small generation. (generated from a set amount of morphisms from adding isos, compositions, and colimits in the arrow cat, 2 out of 3)

1<->2 is reflection theorem -Shaul Ragimov, Tomer M. Schlank

relationship between 1,3 are from the following facts.

L : C->D map of presentable cat. L-equivalences from a stronly saturated class of small generation

if S is a stronly saturated class of small generation of C, then one can define full sub cat D consisting of S local objects. Then D->C induce left adjoint L, and is an accessible localisation. Furthurmore, D is identified with C[S^-1] via L.

-Higher topos theory by Cnossen, appendix B


There is a topos version too. For convenience lets fix T=psh(C)

1. left exact localisation of T. (Automatically a topos)

2. Congruence class of small generation (extra assumption : stable under pullback)

1->2 is taking L-equiv, 2->1 is again same localisation

special instance of 1/2 is "topological localisation". For 1 this means sheafification For 2 this means congruence class generated by monomorphisms.

topological localisation is also equiv to the data of J: Grothendieck topology on a small cat C.

Let me describe J. J is a presheaf on C. for X in C, elements of J(X), called covering sieves, are monomorphisms R->h_X in psh(C), subject to some conditions. J(X) should contain id_hX, restriction maps are via pullbacks, and transitivity.

sh(C,J) are exactly local objects for all covering sieve monomorphisms.

monomorphism R->h_X is also described as full sub cat B of C/x s.t. if Y->X is an object then so is Z->Y->X. This interchange is via straightening and unstraightening.

Y->X is in B iff it is an element in R(Y).

Finally there is description wrt covering maps f_i U_i->X

f_i are covers iff union of im(h_U_i) in h_X is a covering sieve, and B is the category generated by f_i.

J_can(X)={R->h_X s.t. for all Y in C, hom(h_X,h_Y)->hom(R,h_Y) is an isomorphsim} is the finest topology s.t. representable functors become sheaves.

I will assume J has subcanonical topology from now on, which is saying that J is contained in J_can

Observation. Let a denote sheafification. Then, for all R in J(X) aR->h_X is an iso by yoneda. so the perspetive on sieve is a localisation that "enforce monos to be equivalences"

On the other hand, union h_Ui -> im(h_U_i) -> h_X forms an effective epi + mono factorization. and the prev condition is equal to union h_Ui -> h_X becomes an effective epimorphsim. thus the perspective on covers is "enforce covers to be effective epi" which is more related to descent.
